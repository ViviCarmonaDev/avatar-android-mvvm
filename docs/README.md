# Avatar App — Documentación

Bienvenido a la documentación técnica de **Avatar App**, una aplicación Android nativa que permite crear, visualizar y animar avatares 3D personalizados.

## ¿Qué es este proyecto?

Una app educativa/portfolio que combina:
- Desarrollo Android nativo con **Kotlin + Jetpack Compose**
- Arquitectura **MVVM**
- Modelado y animación 3D en **Blender**
- Renderizado 3D en tiempo real con **SceneView (Filament)**
- Persistencia local con **Room**
