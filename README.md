# avatar-android-mvv

App Android nativa con avatares 3D animados, creados en Blender y renderizados con SceneView (Filament).

## Estado del proyecto
🚧 En desarrollo 

## Arquitectura
- Kotlin + Jetpack Compose
- MVVM (ViewModel + StateFlow)
- Navigation Compose
- SceneView (Filament) para renderizado 3D
- Avatares modelados/animados en Blender, exportados a glTF (.glb)

## Estructura del repo
- `app-android/` — proyecto Android Studio
- `blender-assets/avatares/` — archivos .blend originales
- `blender-assets/exports/` — modelos exportados en .glb
